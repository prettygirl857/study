## 学生管理系统

综合运用面向对象、字符串、列表、字典、文件读写等知识点完成的命令行程序。

### 功能

- 添加、删除、修改学生信息
- 查询单个学生 / 查询所有学生
- 数据以 JSON 格式持久化保存
- 启动时自动加载数据，退出时自动保存

学生信息包含：姓名、性别、年龄、手机号、描述信息。

### 运行

```bash
cd 学生管理系统
python main.py
```

按提示输入功能序号（1-7）即可操作。数据保存在 `students.json`，首次运行会自动创建。

### 设计说明

采用「一个角色一个文件」的组织方式：

- **`student.py`** —— 学生类，只负责描述数据，定义了 `__str__` 方便打印
- **`studentcms.py`** —— 管理系统类，负责全部业务逻辑
- **`main.py`** —— 入口文件，只做创建对象和启动两件事

系统内部始终操作 `Student` 对象而非字典，只在写入文件时通过 `__dict__` 转成字典，读取时再还原成对象。

## 环境

Python 3.13（笔记中的 `match case` 语法需要 3.10 以上）
