================================== 补充快捷知识 ==================================

1. 注释
    前面加 #，快捷键为 Ctrl+/

2. 字面量：直接书写的固定数值
    - 数字类型（int, float）：2、-8、-3.6
    - bool（逻辑判断）：True、False（首字母大写，本质为数字 0 和 1）
    - 字符串（str）
    - 空值：None
    - 数据容器：列表、元组、字典...

3. 变量
    - 可以是字符串，也可以是数值
    - 可以一次定义多个变量：base, incr = 10, 20

4. 标识符：为变量、函数、类等元素所起的名字
    命名规范：
        （1）只能包含字母、数字、下划线
        （2）不能以数字开头
        （3）不能使用关键字：True, False, None, and, or, if, else, elif, for, while 等
        （4）严格区分大小写。AGE 和 age 是不同变量

5. 数据类型
    - type(数据)         → 查看数据的类型
    - isinstance(数据, 类型) → 判断数据是否为指定类型，返回 bool


=============================== 一、数据存储与运算 ===============================

1. 字符串（str）
    - 使用单引号、双引号、三引号定义
    - 三引号可以换行：
        s3 = """
        你好！
        祝好
        """

    - 转义字符：字符前面加上反斜线 \
        \n  换行符
        \t  制表符（也可用于缩进）

    - 字符串拼接：
        （1）字面量可以直接拼接，也可以使用 + 拼接
        （2）+ 只能拼接字符串，数字需先用 str() 转换

    - 字符串格式化：
        ① % 占位符：
            s1 = "hhh"
            s2 = "lll"
            print("我是：%s,%s" % (s1, s2))

        ② f"内容{变量}"：
            name = "小明"
            age = 18
            print(f"我是：{name},今年{age}岁")

2. 输入与输出
    - print()  → 输出
    - input()  → 输入
        语法：s = input("提示信息")
        注意：键盘录入的数据均为字符串类型

3. 运算符

    3.1 算术运算符：
        //   整除
        %    取模（10 % 3 → 1）
        **   幂指数（10 ** 3 → 10 的三次方）

    3.2 赋值运算符：
        =    赋值
        +=   如 num += 2 → num = num + 2
        -=、*=、/=、%=、//=、**=  用法一致

    3.3 比较运算符（结果为 bool 值）：
        ==   等于
        !=   不等于
        >    大于
        >=   大于等于
        <    小于
        <=   小于等于

    3.4 逻辑运算符（结果为 bool 值）：
        and   逻辑与
        or    逻辑或
        not   逻辑非（取反）

        # not 示例：
        flag = True
        print(not flag)        # False
        print(not (3 > 5))     # True（3>5 为 False，取反后为 True）


=============================== 二、流程语句 ===============================

1. if 条件判断
    注意：if 代码块需要缩进，不缩进的语句不再属于 if 语句
    条件为 bool 值

    ① 单分支（if）：
        if 条件:
            条件成立执行的代码

    ② 双分支（if-else）：
        if 条件:
            条件成立执行的代码
        else:
            条件不成立执行的代码

    ③ 多分支（if-elif-else）：
        if 条件1:
            条件1成立执行的代码
        elif 条件2:
            条件2成立执行的代码
        else:
            以上都不成立执行的代码

    # 示例：
    score = 85
    if score >= 90:
        print("优秀")
    elif score >= 60:
        print("及格")
    else:
        print("不及格")

2. match case 模式匹配

    # 示例：
    score = 85
    match score:
        case 100:
            print("满分")
        case score if score >= 90:
            print("优秀")
        case score if score >= 60:
            print("及格")
        case _:
            print("不及格")

    # 格式：
    # match 变量:
    #     case 匹配值1:
    #         执行的代码
    #     case 匹配值2:
    #         执行的代码
    #     case _:             ← _ 是通配符，匹配所有情况，类似 else

3. while 循环
    格式：
        while 条件:
            条件成立重复执行的代码

    # ① 基础示例：
    i = 1
    while i <= 5:
        print(i)
        i += 1                    # 输出：1 2 3 4 5

    # ② 无限循环（配合 break 退出）：
    while True:
        name = input("请输入名字(输入q退出)：")
        if name == "q":
            break                  # 退出循环
        print(f"你好，{name}")

4. for 循环
    格式：
        for 变量 in 可迭代对象:
            重复执行的代码

    特点：
        - 自动逐个取元素，不需要手动控制索引，不会越界
        - 遍历次数由对象长度决定
        - 遍历结束，自动退出循环

    # ① 遍历字符串：
    for ch in "hello":
        print(ch)                   # 输出：h e l l o（逐个字符）

    # ② 配合 range() 控制次数：
    for i in range(5):
        print(i)                    # 输出：0 1 2 3 4

    # range() 的三种写法：
    range(5)         # 0,1,2,3,4         → 循环 5 次
    range(1, 6)      # 1,2,3,4,5         → 从 1 开始，到 5 结束
    range(1, 10, 2)  # 1,3,5,7,9         → 步长为 2

5. 嵌套循环
    格式：一个循环里面再放一个循环

    # 打印 99 乘法表：
    for i in range(1, 10):
        for j in range(1, i + 1):
            print(f"{j}×{i}={i * j}", end="\t")
        print()    # 换行

    # 输出效果：
    # 1×1=1
    # 1×2=2   2×2=4
    # 1×3=3   2×3=6   3×3=9
    # ...
    # 1×9=9   2×9=18  3×9=27  ...  9×9=81


=============================== 三、数据容器 ===============================

类似于 C 语言中的数组，可以存放多个数据

1. 列表（list）：用 [] 定义，可修改、可重复、有序
    定义：
        s = [2, 55, 95, 56, 4, 452, 56, 46]

    特点：
        - 可以储存不同类型的元素
        - 元素有序，可重复，元素可以修改
        - 正向索引从 0 开始：s[0] = 2
        - 反向索引从 -1 开始：s[-1] = 46

    切片：截取列表的一部分
        语法：s[开始索引:结束索引:步长]
        示例：s[0:6:2] → [2, 95, 4, 56]
        注意：开始索引未指定默认 0，结束索引未指定默认到结尾，步长未指定默认 1

    常用方法：
        方法                作用                                     样例
        append(元素)         在列表尾部追加元素                        s.append(10)
        insert(索引, 元素)   在指定索引前插入元素                      s.insert(0, 92)
        remove(元素)         移除第一个匹配到的值                      s.remove(56)
        pop(索引)            删除指定索引元素（不写删最后一个）          s.pop(2) / s.pop()
        sort()               对列表排序（元素类型需一致）               s.sort()
        reverse()            反转列表元素                              s.reverse()

2. 字符串（str）：用 '' 或 "" 或 """ """ 定义，不可修改、有序、可迭代
    定义：
        s1 = 'hello'
        s2 = "你好"
        s3 = """
               多行
              字符串
              """

    特点：
        - 不可变性：一旦创建，无法修改其中的字符
        - 有序性：每个字符都有对应的索引位置
        - 可迭代性：可以被 for 循环逐个遍历

    索引：
        - 正向索引从 0 开始：s1[0] = 'h'
        - 反向索引从 -1 开始：s1[-1] = 'o'

    切片：截取字符串的一部分
        语法：字符串[开始索引:结束索引:步长]
        特点同列表切片

    常用方法：
        方法                作用                                             样例
        find(子串)          查找子串，返回第一次出现的索引，找不到返回 -1       s.find('Python')
        count(子串)         统计子串出现的次数                                 s.count('H')
        upper()             将所有字母转为大写                                 s.upper()
        lower()             将所有字母转为小写                                 s.lower()
        split(分隔符)       按分隔符分割成列表                                 s.split(' ')
        strip()             去除两端空白字符（可指定要去除的字符）               s.strip() / s.strip('*')
        replace(旧, 新)     将旧子串替换为新子串                               s.replace('H', 'C')
        startswith(子串)    检查是否以指定子串开头，返回 bool                   s.startswith('P')

3. 元组（tuple）：用 () 定义，不可修改、有序、可重复
    定义：
        t = (1, 2, 3)            # 标准写法
        t2 = 10, 20, 30          # 省略括号，也是元组

    特点：
        - 与列表类似，但一旦定义就不能修改（增、删、改都不行）
        - 可以查询、切片、遍历

    常用方法：
        方法      作用                                  样例
        count()   统计某元素在元组中出现的次数             t.count(2)
        index()   查找元素第一次出现的索引位置             t.index(3)

    切片：同列表，语法：元组[开始:结束:步长]

    组包与解包：
        组包：将多个值合并到一个元组中
            t = 1, 2, 3         # 把 1、2、3 打包成元组 (1, 2, 3)

        解包：将元组中的元素拆开，分别赋值给多个变量
            a, b, c = t         # a=1, b=2, c=3（变量数量必须和元素数量一致）

        # 常用场景：交换两个变量的值
        x, y = y, x             # 右边先组包，左边再解包

        # 用 * 接收多余的元素
        a, *b = (1, 2, 3, 4)    # a=1, b=[2, 3, 4]

4. 集合（set）：用 {} 定义，无序、不可重复、可修改
    特点：
        - 无序：元素没有索引位置，不能用下标访问
        - 不可重复：自动去重，重复元素只保留一个
        - 可修改：可以添加或删除元素

    定义：
        s = {1, 2, 3}             # 普通集合
        s2 = set()                # 空集合（不能写 {}，那是空字典）

    注意：集合会自动去重
        s = {1, 1, 2, 3}          # 实际为 {1, 2, 3}

    常用方法：
        方法            作用                           样例
        add(元素)        添加元素到集合中               s.add(4)
        remove(元素)     移除集合中的指定元素            s.remove(2)
        pop()            随机删除集合中的一个元素并返回   s.pop()
        clear()          清空集合                       s.clear()

    集合运算：
        difference(另一集合)       差集                     s1.difference(s2)
        union(另一集合)            并集                     s1.union(s2)
        intersection(另一集合)     交集                     s1.intersection(s2)

5. 字典（dict）：用 {} 定义，存储键值对（key: value），可通过 key 找到对应的 value
    特点：
        - key 不能重复，value 可以重复
        - key 通常使用字符串类型

    定义：
        dict1 = {"小智": 675, "李思": 608, "李琪": 478, "小黑": 545, "温韬": 429}
        空字典 = {} = dict()

    常用操作：
        操作      语法                       含义                           样例
        添加      字典[key] = value          添加键值对                      dict1["涛哥"] = 688
        删除      字典.pop(key)              删除指定 key，返回对应的 value    score = dict1.pop("涛哥")
        删除      del 字典[key]              删除指定键值对（不返回值）         del dict1["涛哥"]
        修改      字典[key] = value          修改已有 key 对应的值             dict1["小智"] = 658
        查询      字典[key]                  根据 key 获取 value              dict1["涛哥"]
        查询      字典.get(key)              根据 key 获取 value              dict1.get("涛哥")
        查询      字典.keys()                获取所有的 key                   dict1.keys()
        查询      字典.values()              获取所有的 value                 dict1.values()
        查询      字典.items()               获取所有的 key-value 键值对       dict1.items()


=============================== 四、函数 ===============================

函数是组织好的、可重复使用的、用来实现特定功能的代码片段

1. 函数定义与调用
    格式：
        def 函数名(参数列表):
            函数体
            ......
            return 返回值

    注意：
        - 参数列表、返回值可有可无，根据需求确定
        - 函数必须先定义后调用（定义时内部代码不执行，调用时才执行）
        - 函数若有多个参数，使用 , 分隔

    # 示例：计算圆的面积
    def circle_area(r):
        area = 3.14 * r * r
        return area

    c_area = circle_area(10)
    print(c_area)

2. 参数传递方式

    以下示例共用 introduce 函数：
        def introduce(name, age, city):
            “””
            打印个人介绍信息

            :param name: 姓名
            :param age: 年龄
            :param city: 所在城市
            “””
            print(f”我是{name}，今年{age}岁，来自{city}”)

    2.1 位置参数：按顺序传递
        introduce(“小明”, 18, “北京”)
        # 输出：我是小明，今年18岁，来自北京

    2.2 关键字参数：按名字传递（顺序可以不固定）
        introduce(age=18, city=”北京”, name=”小明”)
        # 输出：我是小明，今年18岁，来自北京

        注意：混合使用时，位置参数必须在关键字参数前面

    2.3 默认参数：定义时为参数提供默认值，调用时可不传
        def reg_stu(name, age, gender, city=”北京”):
            print(f”注册成功, 姓名:{name}, 年龄:{age}, 性别:{gender}, 城市:{city}”)
            return {“name”: name, “age”: age, “gender”: gender, “city”: city}

        # 不传 city，使用默认值
        stu = reg_stu(“张三”, 18, “男”)
        # 输出：注册成功, 姓名:张三, 年龄:18, 性别:男, 城市:北京

        # 传了 city，覆盖默认值
        stu = reg_stu(“赵四”, 22, “男”, “深圳”)
        # 输出：注册成功, 姓名:赵四, 年龄:22, 性别:男, 城市:深圳

        注意：
            - 默认参数必须放在没有默认值的参数后面
            - 一个函数可以设置多个默认值
            - 调用时传了值则覆盖默认值，没传则使用默认值

    2.4 不定长参数：参数个数不确定时使用

        （1）位置传递（*args）：接收多个位置参数，封装为元组
            def calc_data(*arges):
                min_data = min(arges)
                max_data = max(arges)
                avg_data = sum(arges) / len(arges)
                return min_data, max_data, avg_data

            data = calc_data(10, 20, 30, 40, 50)
            print(data)

        （2）关键字传递（**kwarges）：接收多个关键字参数，封装为字典
            def calc_data(*arges, **kwarges):
                “””
                计算一组数据的最大值、最小值及平均值

                :param arges: 可变位置参数，接收多个数值
                :param kwarges: 可变关键字参数，如 round=2 控制保留小数位数
                :return: 最小值、最大值、平均值
                “””
                min_data = min(arges)
                max_data = max(arges)
                avg_data = sum(arges) / len(arges)

                if kwarges.get('round'):
                    avg_data = round(avg_data, kwarges.get('round'))

                return min_data, max_data, avg_data

            data = calc_data(100, 200, 300, 400, round=2, count=0)
            print(data)

        注意：
            - “键=值”形式的参数会被 **kwarges 接收，合并封装为一个字典
            - kwarges 只是约定俗成的变量名，可以使用任何合法的变量名（如 **options）

    2.5 参数类型概览
        - 普通参数：数字、布尔、字符串、列表、元组、集合、字典等
        - 特殊参数：函数（函数也可以作为参数传递给另一个函数）

3. 返回值（return）
    - return 用于将函数内部的结果返回给调用者
    - 函数可以有多个返回值，用 , 分隔（实际返回的是一个元组）
    - return 只有返回功能，没有输出打印的功能
    - 函数若没有 return，默认返回 None

4. 函数说明文档（docstring）
    写在函数开头，用三个引号包裹，用于解释函数的功能、参数、返回值等

    # 示例：
    def circle_area(r):
        “””
        计算圆的面积

        :param r: 圆的半径
        :return: 圆的面积
        “””
        area = 3.14 * r * r
        return area

    查看说明文档：
        - 使用 help() 函数：help(circle_area)
        - 鼠标悬浮在函数名上，VS Code 自动显示

5. 函数的嵌套
    在一个函数中调用另外一个函数
    函数调用遵循栈结构：后进先出

6. 变量作用域
    - 全局变量：在函数之外定义的变量，整个文件（包括函数内）都可以使用
    - 局部变量：在函数内部定义的变量，只能在函数内部使用，外部无法访问
      （函数执行完毕后，会自动销毁其内部局部变量）
    注意：尽量避免在函数中使用全局变量，会使代码难以维护

7. 匿名函数（lambda）
    匿名函数是没有名称的函数，通过 lambda 表达式声明，适用于简单的单行函数

    定义格式：
        lambda 参数列表: 函数体

    # 示例：
    out_line = lambda: print('..........')
    add = lambda x, y: x + y

    # 调用
    out_line()
    print(add(100, 200))

    注意：
        - 逻辑简单且只在一个地方使用时，可考虑使用匿名函数，简化书写
        - 通常作为高阶函数的参数使用（如 map、filter、sorted 等）
        - 匿名函数可以返回结果，不需要写 return，表达式的运行结果就是返回值

8.递归
    在函数中，自己调用自己的情况。递归调用一定要有终结点
    #计算n的阶乘
    def jc(n):
        if n==1:
            return 1
        else:
            return n*jc(n-1)
    
    print(jc(10))

=============================== 五、类型注解 ===============================

类型注解是 Python 中的一种语法特性，用于明确标识变量、函数参数和返回值的数据类型，使代码更清晰、更易维护
注意：类型注解只是提示，不影响代码运行，Python 解释器不会强制检查类型

1. 变量类型注解
    语法：
        变量名: 类型 = 值

    # 定义变量
    a: int = 695
    score: float = 98.5
    hobby: str = "Python"
    flag: bool = True
    pic: None = None

    names: list[str] = ["A", "C", "E"]
    phones: set[str] = {"13309091111", "15209109121"}
    options: dict[str, int] = {"count": 0, "total": 0}
    goods: tuple[str, int, int] = ("手机", 5999, 1)

2. 函数类型注解
    语法：def 函数名(参数: 类型, ...) -> 返回值类型:

    # 有参数和返回值
    def add(x: int, y: int) -> int:
        return x + y

    def circle_area(r: float) -> float:
        return 3.14 * r * r

    def greet(name: str) -> str:
        return f"你好，{name}"

    # 无返回值，标注为 None
    def say_hello(name: str) -> None:
        print(f"你好，{name}")

    # 参数和返回值都可以是容器类型
    def get_top3(scores: list) -> list:
        scores.sort(reverse=True)
        return scores[:3]

    # 类型注解 + 默认参数
    def reg_stu(name: str, age: int, gender: str, city: str = "北京") -> dict:
        return {"name": name, "age": age, "gender": gender, "city": city}


=============================== 六、模块 ===============================

1. 模块的概念
    一个 .py 文件就是一个模块，模块是 Python 程序的基本组成单位
    在模块中可以定义变量、函数、类以及可执行的代码

    优势：提高代码复用性、降低开发门槛、避免命名冲突

2. 导入模块

    语法                              代码示例                                    调用方式
    import 模块名                     import random                              random.randint(10, 100)
    import 模块名 as 别名             import random as rd                        rd.randint(10, 100)
    from 模块名 import 功能名          from random import randint, choice         直接使用：randint(10, 100)
    from 模块名 import 功能名 as 别名  from random import randint as rint          直接使用：rint(10, 100)
    from 模块名 import *              from random import *                       导入所有功能，直接用函数名调用

    注意：
        - import 可以一次导入多个模块，用 , 分隔：import os, sys, math
        - from 模块名 import * 不推荐使用，可能造成命名冲突

3. 常用内置模块

    模块          主要用途                      示例
    os            文件、目录、系统环境操作         os.getcwd() → 获取当前工作目录
    sys           Python 解释器、命令行参数        sys.argv → 命令行参数列表
    math          数学计算                        math.sqrt(16) → 4.0
    random        随机数                          random.randint(1, 10) → 1~10 随机整数
    datetime      日期和时间                      datetime.datetime.now() → 当前时间
    json          JSON 数据读写                   json.dumps({"a": 1}) → '{"a": 1}'
    re            正则表达式                      re.search(r'\d+', "abc123")
    collections  常用高级数据结构                 from collections import Counter




4. 自定义模块
    模块名为自己定义的文件名（不需要带上 .py）

5. __name__ 变量
    每个模块都有一个内置变量 __name__，用于判断当前模块是被直接运行还是被导入

    - 直接运行本文件 → __name__ 的值为 "__main__"
    - 被其他文件 import → __name__ 的值为本模块的文件名

    # 作用：测试代码写在 if 里面，只有直接运行时才执行，被 import 时不会触发

    # 示例：my_utils.py
        def add(x, y):
            return x + y

        # 下面的测试代码被 import 时不会执行
        if __name__ == "__main__":
            print(add(3, 5))           # 只有直接运行 my_utils.py 才会打印

6. 包（package）
    本质就是一个文件夹，该文件夹中可以包含若干个模块，文件夹下还包含一个 __init__.py 来描述包的信息
    作用：模块文件较多时，来管理多个模块（包的本质也是一个模块）
    定义 __init__ 文件后，文件会自动变成软件包

    导入方式：
        import 包名.模块名
        from 包名 import 模块名
        from 包名.模块名 import 功能名


=============================== 七、面向对象基础 ===============================

1. 面向对象的概念

    面向过程编程：
        核心思想是把一个需求分解成一系列要执行的步骤，然后按照步骤依次执行这些任务（关注的是流程、步骤）
        适用于一些简单线性编程

    面向对象编程：
        万物皆对象，对象的特征为属性，对象的功能为方法

2. 类与对象

    类：描述一组具有相同属性和方法的模板
    对象：对象是类的实例，是基于类创建出来的

3. 类的定义与对象的创建

    方法一（不推荐）：

        # 定义类
        class 类名:
            pass

        # 创建对象
        对象名 = 类名()
        对象名.属性名1 = 属性值1
        对象名.属性名2 = 属性值2

        说明：
            - 类名的命名规范遵循大驼峰法，每个单词的首字母都大写，单词之间没有分隔符，比如：UserInfo、UserAccount
            - __dict__ 是 Python 中用户定义类实例的一个特殊属性，用于以字典形式储存对象的属性

    方法二（推荐）：

        # 定义类
        class 类名:
            def __init__(self, 参数列表):
                self.属性名 = 参数值
                self.属性名 = 参数值

        # 创建对象
        对象名 = 类名(参数列表)

        说明：
            - self：方法的第一个参数，表示当前创建的实例对象
            - __init__：初始化方法，对象创建后自动调用，主要用于设置对象的初始状态（设置对象属性）
            - def 在类外称之为函数，在类中称之为方法

        # 示例：
        class Car:
            def __init__(self, c_brand, c_name, c_price):
                self.brand = c_brand
                self.name = c_name
                self.price = c_price

        c1 = Car("宝马", "X5", 800000)
        print(c1.__dict__)

4. 实例方法

    在类中定义的函数称为方法，第一个参数必须是 self
    通过对象来调用，调用时 self 会自动传入，不需要手动传递

    格式：
        class 类名:
            def __init__(self, 参数列表):
                self.属性名 = 参数值

            def 方法名(self, 形参列表):
                # 方法体

    # 示例：
        class Car:
            def __init__(self, c_brand, c_name, c_price):
                self.brand = c_brand
                self.name = c_name
                self.price = c_price

            def show_info(self):
                print(f"品牌：{self.brand}，车型：{self.name}，价格：{self.price}")

            def discount(self, rate):
                self.price = self.price * (1 - rate)

        # 创建对象并调用方法
        c1 = Car("宝马", "X5", 800000)
        c1.show_info()           # 品牌：宝马，车型：X5，价格：800000
        c1.discount(0.1)         # 打九折
        c1.show_info()           # 品牌：宝马，车型：X5，价格：720000.0

5. 魔法方法

    魔法方法是 Python 中以双下划线开头和结尾的特殊方法，用于定义类的特殊行为，比如 __init__
    魔法方法不需要手动调用，由解释器自动调用

    常见的魔法方法：
        方法                      作用
        __init__                  初始化方法，对象创建时自动调用
        __str__                   字符串表示方法，print(对象) 或 str(对象) 时调用
        __eq__                    比较两个对象是否相等（equal），使用 == 时调用
        __lt__                    小于（<）
        __le__                    小于等于（<=）
        __gt__                    大于（>）
        __ge__                    大于等于（>=）

6. 属性

    实例属性：属于每个具体对象的属性，各个对象相互独立（每个对象特有的数据）

    类属性：属于类本身的属性，所有实例共享

    # 示例：
    class Student:
        # 类属性：所有学生共享
        school = "蓝翔技校"

        def __init__(self, name, age):
            # 实例属性：每个学生各不相同
            self.name = name
            self.age = age

    # 创建两个对象，实例属性各自独立，类属性共享
    stu1 = Student("小明", 18)
    stu2 = Student("小红", 19)

    print(stu1.school)    # 蓝翔技校
    print(stu2.school)    # 蓝翔技校
    Student.school = "新东方技校"     # 修改类属性
    print(stu1.school)    # 新东方技校（stu1 也变了）
    print(stu2.school)    # 新东方技校（stu2 也变了）


=============================== 八、异常 ===============================

1. 异常的概念

    什么是异常：程序运行过程中出现的错误，它会中断程序的正常执行流程

    常见异常类型：
        异常类型              说明
        NameError              变量名不存在
        TypeError              类型错误（如字符串 + 数字）
        ValueError             值错误（如 int("abc")）
        ZeroDivisionError      除数为零
        IndexError             列表索引超出范围
        KeyError               字典 key 不存在
        FileNotFoundError      文件未找到

2. 异常处理

    不做处理：有 bug，中断执行

    捕获异常：按照我们自己的方式处理，处理完异常后程序继续执行
    （编写程序时，做好预案，出现异常按预案处理）

    语法：
        try:
            可能会出现异常的业务代码
        except [异常类型 as 变量名]:
            出现异常时的预案
        finally:
            不管是否出现异常，都会执行的代码

    # 示例：
        try:
            num = int(input("请输入数字："))
            print(100 / num)
        except ValueError:
            print("输入的不是数字！")
        except ZeroDivisionError:
            print("除数不能为零！")
        except Exception as e:
            print(f"未知错误：{e}")
        finally:
            print("程序结束")

    注意：Exception 可以匹配所有类型异常
