【1】字符串（str）
──────────────────────────────────────────────

  ● 定义：单引号 / 双引号 / 三引号，三引号可换行

        s3 = """
        你好！
        祝好
        """

  ● 转义字符：字符前加反斜线 \

        \n      换行符
        \t      制表符（也可用于缩进）

  ● 拼接
        (1) 字面量可直接相邻拼接，也可用 + 拼接
        ⚠ (2) + 只能拼接字符串，数字要先用 str() 转换

  ★ 字符串格式化（两种写法）

    ① % 占位符
        s1 = "hhh"
        s2 = "lll"
        print("我是：%s,%s" % (s1, s2))

    ② f-string（推荐）  f"内容{变量}"
        name = "小明"
        age = 18
        print(f"我是：{name},今年{age}岁")


【2】输入与输出
──────────────────────────────────────────────
    print()     输出

【3】运算符
──────────────────────────────────────────────

  ● 3.1 算术运算符（只记特殊的）
        //      整除
        %       取模            10 % 3   → 1
        **      幂指数          10 ** 3  → 10 的三次方

  ● 3.2 赋值运算符
        =       赋值
        +=      num += 2  等价于  num = num + 2
        -=  *=  /=  %=  //=  **=        用法一致

  ● 3.3 比较运算符（结果为 bool）
        ==  等于        !=  不等于
        >   大于        >=  大于等于
        <   小于        <=  小于等于

  ● 3.4 逻辑运算符（结果为 bool）
        and     逻辑与
        or      逻辑或
        not     逻辑非（取反）

        ▸ not 示例：
            flag = True
            print(not flag)        → False
            print(not (3 > 5))     → True    （3>5 为 False，取反为 True）

  二、流 程 语 句
════════════════════════════════════════════════════════════════════════════════

【1】if 条件判断
──────────────────────────────────────────────
    ⚠ if 代码块必须缩进；不缩进的语句就不再属于 if
    ⚠ 条件的结果是 bool 值

    ① 单分支                    ② 双分支                 ③ 多分支
    ─────────────────           ─────────────────        ─────────────────
    if 条件:                    if 条件:                 if 条件1:
        成立时执行                  成立时执行               条件1成立时执行
                                else:                    elif 条件2:
                                    不成立时执行             条件2成立时执行
                                                         else:
                                                             都不成立时执行

    ▸ 示例：
        score = 85
        if score >= 90:
            print("优秀")
        elif score >= 60:
            print("及格")
        else:
            print("不及格")


【2】match case 模式匹配
──────────────────────────────────────────────
    格式：
        match 变量:
            case 匹配值1:
                执行的代码
            case 匹配值2:
                执行的代码
            case _:              ★ _ 是通配符，匹配所有情况，类似 else

    ▸ 示例：
        score = 85
        match score:
            case 100:
                print("满分")
            case score if score >= 90:      # case 后可加 if 追加条件
                print("优秀")
            case score if score >= 60:
                print("及格")
            case _:
                print("不及格")


【3】while 循环
──────────────────────────────────────────────
    格式：
        while 条件:
            条件成立时重复执行的代码

    ▸ ① 基础用法
        i = 1
        while i <= 5:
            print(i)
            i += 1              → 1 2 3 4 5

    ▸ ② 无限循环 + break 退出
        while True:
            name = input("请输入名字(输入q退出)：")
            if name == "q":
                break                       ★ break 用于退出循环
            print(f"你好，{name}")


【4】for 循环
──────────────────────────────────────────────
    格式：
        for 变量 in 可迭代对象:
            重复执行的代码

    ★ 特点
        - 自动逐个取元素，不需要手动控制索引，不会越界
        - 遍历次数由对象长度决定
        - 遍历结束自动退出循环

    ▸ ① 遍历字符串
        for ch in "hello":
            print(ch)           → h e l l o（逐个字符）

    ▸ ② 配合 range() 控制次数
        for i in range(5):
            print(i)            → 0 1 2 3 4

    ★ range() 的三种写法
        range(5)            → 0,1,2,3,4        循环 5 次
        range(1, 6)         → 1,2,3,4,5        从 1 开始，到 5 结束（不含 6）
        range(1, 10, 2)     → 1,3,5,7,9        步长为 2


【5】嵌套循环
──────────────────────────────────────────────
    一个循环里面再放一个循环

    ▸ 打印 99 乘法表：
        for i in range(1, 10):
            for j in range(1, i + 1):
                print(f"{j}×{i}={i * j}", end="\t")
            print()                     # 内层跑完换一行

    → 输出效果：
        1×1=1
        1×2=2   2×2=4
        1×3=3   2×3=6   3×3=9
        ...
        1×9=9   2×9=18  3×9=27  ...  9×9=81



════════════════════════════════════════════════════════════════════════════════
  三、数 据 容 器
════════════════════════════════════════════════════════════════════════════════

类似于 C 语言中的数组，可以存放多个数据。

★ 五种容器速查
──────────────────────────────────────────────
    容器        符号        有序    可重复    可修改
    list        [ ]          √       √         √
    str        '' " " """    √       √         ×
    tuple       ( )          √       √         ×
    set         { }          ×       ×         √
    dict     {key: value}    √     key 不可重复  √


【1】列表 list —— [] 定义，可修改、可重复、有序
──────────────────────────────────────────────
    定义：
        s = [2, 55, 95, 56, 4, 452, 56, 46]

    ★ 特点
        - 可以储存不同类型的元素
        - 元素有序、可重复、可修改
        - 正向索引从  0 开始      s[0]  = 2
        - 反向索引从 -1 开始      s[-1] = 46

    ★ 切片：截取列表的一部分
        语法：s[开始索引 : 结束索引 : 步长]
        ▸ s[0:6:2]  →  [2, 95, 4, 56]
        ⚠ 开始默认 0，结束默认到结尾，步长默认 1

    常用方法：
        append(元素)            在列表尾部追加元素            ▸ s.append(10)
        insert(索引, 元素)      在指定索引前插入元素          ▸ s.insert(0, 92)
        remove(元素)            移除第一个匹配到的值          ▸ s.remove(56)
        pop(索引)               删除指定索引元素，不写则删最后一个
                                                              ▸ s.pop(2) / s.pop()
        sort()                  排序（⚠ 元素类型需一致）      ▸ s.sort()
        reverse()               反转列表元素                  ▸ s.reverse()


【2】字符串 str —— '' / "" / """ """ 定义，不可修改、有序、可迭代
──────────────────────────────────────────────
    定义：
        s1 = 'hello'
        s2 = "你好"
        s3 = """
               多行
              字符串
              """

    ★ 三大特性
        - 不可变性：一旦创建，无法修改其中的字符
        - 有序性：每个字符都有对应的索引位置
        - 可迭代性：可以被 for 循环逐个遍历

    索引：正向从 0 开始 s1[0] = 'h'      反向从 -1 开始 s1[-1] = 'o'
    切片：语法与特点同列表  字符串[开始 : 结束 : 步长]

    常用方法：
        find(子串)          查找子串，返回首次出现的索引；找不到返回 -1
                                                          ▸ s.find('Python')
        count(子串)         统计子串出现的次数            ▸ s.count('H')
        upper()             所有字母转大写                ▸ s.upper()
        lower()             所有字母转小写                ▸ s.lower()
        split(分隔符)       按分隔符分割成列表            ▸ s.split(' ')
        strip()             去除两端空白（可指定字符）    ▸ s.strip() / s.strip('*')
        replace(旧, 新)     将旧子串替换为新子串          ▸ s.replace('H', 'C')
        startswith(子串)    是否以指定子串开头，返回 bool ▸ s.startswith('P')


【3】元组 tuple —— () 定义，不可修改、有序、可重复
──────────────────────────────────────────────
    定义：
        t  = (1, 2, 3)          # 标准写法
        t2 = 10, 20, 30         # 省略括号，也是元组

    ★ 特点：与列表类似，但一旦定义就不能修改（增、删、改都不行）
             可以查询、切片、遍历

    常用方法：
        count()         统计某元素出现的次数          ▸ t.count(2)
        index()         查找元素首次出现的索引        ▸ t.index(3)

    切片：同列表   元组[开始 : 结束 : 步长]

    ★ 组包与解包
        组包 —— 将多个值合并到一个元组中
            t = 1, 2, 3             # 打包成 (1, 2, 3)

        解包 —— 将元组元素拆开，分别赋值给多个变量
            a, b, c = t             # a=1, b=2, c=3
            ⚠ 变量数量必须和元素数量一致

        ▸ 常用场景：交换两个变量的值
            x, y = y, x             # 右边先组包，左边再解包

        ▸ 用 * 接收多余的元素
            a, *b = (1, 2, 3, 4)    # a=1, b=[2, 3, 4]


【4】集合 set —— {} 定义，无序、不可重复、可修改
──────────────────────────────────────────────
    ★ 特点
        - 无序：元素没有索引位置，不能用下标访问
        - 不可重复：自动去重，重复元素只保留一个
        - 可修改：可以添加或删除元素

    定义：
        s  = {1, 2, 3}          # 普通集合
        s2 = set()              ⚠ 空集合只能这样写，{} 是空字典

    ⚠ 自动去重：  s = {1, 1, 2, 3}   实际为 {1, 2, 3}

    常用方法：
        add(元素)       添加元素到集合中                ▸ s.add(4)
        remove(元素)    移除集合中的指定元素            ▸ s.remove(2)
        pop()           随机删除一个元素并返回          ▸ s.pop()
        clear()         清空集合                        ▸ s.clear()

    集合运算：
        difference(另一集合)      差集      ▸ s1.difference(s2)
        union(另一集合)           并集      ▸ s1.union(s2)
        intersection(另一集合)    交集      ▸ s1.intersection(s2)


【5】字典 dict —— {} 定义，存储键值对 key: value
──────────────────────────────────────────────
    通过 key 找到对应的 value

    ★ 特点
        - key 不能重复，value 可以重复
        - key 通常使用字符串类型

    定义：
        dict1 = {"小智": 675, "李思": 608, "李琪": 478, "小黑": 545, "温韬": 429}
        空字典 = {} = dict()

    常用操作：
        [ 增 / 改 ]
        字典[key] = value       key 不存在则添加，存在则修改
                                ▸ dict1["涛哥"] = 688      添加
                                ▸ dict1["小智"] = 658      修改

        [ 删 ]
        字典.pop(key)           删除指定 key，并返回其 value
                                ▸ score = dict1.pop("涛哥")
        del 字典[key]           删除指定键值对（不返回值）
                                ▸ del dict1["涛哥"]

        [ 查 ]
        字典[key]               根据 key 取 value          ▸ dict1["涛哥"]
        字典.get(key)           根据 key 取 value          ▸ dict1.get("涛哥")
        字典.keys()             获取所有的 key
        字典.values()           获取所有的 value
        字典.items()            获取所有的 key-value 键值对



════════════════════════════════════════════════════════════════════════════════
  四、函 数
════════════════════════════════════════════════════════════════════════════════

函数是组织好的、可重复使用的、用来实现特定功能的代码片段。

【1】定义与调用
──────────────────────────────────────────────
    格式：
        def 函数名(参数列表):
            函数体
            ......
            return 返回值

    ⚠ 注意
        - 参数列表、返回值可有可无，根据需求确定
        - 必须先定义后调用（定义时内部代码不执行，调用时才执行）
        - 多个参数之间用 , 分隔

    ▸ 示例：计算圆的面积
        def circle_area(r):
            area = 3.14 * r * r
            return area

        c_area = circle_area(10)
        print(c_area)


【2】参数传递方式
──────────────────────────────────────────────
  以下 2.1 ~ 2.2 共用这个函数：

        def introduce(name, age, city):
            """
            打印个人介绍信息

            :param name: 姓名
            :param age:  年龄
            :param city: 所在城市
            """
            print(f"我是{name}，今年{age}岁，来自{city}")

  ● 2.1 位置参数 —— 按顺序传递
        introduce("小明", 18, "北京")
        → 我是小明，今年18岁，来自北京

  ● 2.2 关键字参数 —— 按名字传递，顺序可以不固定
        introduce(age=18, city="北京", name="小明")
        → 我是小明，今年18岁，来自北京

        ⚠ 混合使用时，位置参数必须写在关键字参数前面

  ● 2.3 默认参数 —— 定义时给默认值，调用时可不传
        def reg_stu(name, age, gender, city="北京"):
            print(f"注册成功, 姓名:{name}, 年龄:{age}, 性别:{gender}, 城市:{city}")
            return {"name": name, "age": age, "gender": gender, "city": city}

        stu = reg_stu("张三", 18, "男")               # 不传 city，用默认值
        → 注册成功, 姓名:张三, 年龄:18, 性别:男, 城市:北京

        stu = reg_stu("赵四", 22, "男", "深圳")       # 传了 city，覆盖默认值
        → 注册成功, 姓名:赵四, 年龄:22, 性别:男, 城市:深圳

        ⚠ 注意
            - 默认参数必须放在「没有默认值的参数」后面
            - 一个函数可以设置多个默认值
            - 传了值就覆盖默认值，没传就用默认值

  ● 2.4 不定长参数 —— 参数个数不确定时使用
        ★ *args   接收多个位置参数，封装为「元组」
        ★ **kwargs 接收多个关键字参数，封装为「字典」

    (1) 位置传递 *args
        def calc_data(*args):
            min_data = min(args)
            max_data = max(args)
            avg_data = sum(args) / len(args)
            return min_data, max_data, avg_data

        data = calc_data(10, 20, 30, 40, 50)
        print(data)

    (2) 关键字传递 **kwargs
        def calc_data(*args, **kwargs):
            """
            计算一组数据的最大值、最小值及平均值

            :param args:   可变位置参数，接收多个数值
            :param kwargs: 可变关键字参数，如 round=2 控制保留小数位数
            :return: 最小值、最大值、平均值
            """
            min_data = min(args)
            max_data = max(args)
            avg_data = sum(args) / len(args)

            if kwargs.get('round'):
                avg_data = round(avg_data, kwargs.get('round'))

            return min_data, max_data, avg_data

        data = calc_data(100, 200, 300, 400, round=2, count=0)
        print(data)

        ⚠ 注意
            - 「键=值」形式的参数会被 **kwargs 接收，合并封装为一个字典
            - args / kwargs 只是约定俗成的名字，可用任何合法变量名（如 **options）

  ● 2.5 参数类型概览
        普通参数：数字、布尔、字符串、列表、元组、集合、字典等
        特殊参数：函数（函数也可以作为参数传给另一个函数）


【3】返回值 return
──────────────────────────────────────────────
    - 把函数内部的结果返回给调用者
    - 可以有多个返回值，用 , 分隔（★ 实际返回的是一个元组）
    ⚠ return 只有「返回」功能，没有「打印输出」功能
    ⚠ 函数若没有 return，默认返回 None


【4】函数说明文档 docstring
──────────────────────────────────────────────
    写在函数开头，用三个引号包裹，解释功能、参数、返回值

    ▸ 示例：
        def circle_area(r):
            """
            计算圆的面积

            :param r: 圆的半径
            :return: 圆的面积
            """
            area = 3.14 * r * r
            return area

    查看方式：
        - help(circle_area)
        - 鼠标悬浮在函数名上，VS Code 自动显示


【5】函数的嵌套
──────────────────────────────────────────────
    在一个函数中调用另外一个函数
    ★ 函数调用遵循栈结构：后进先出


【6】变量作用域
──────────────────────────────────────────────
    全局变量：在函数之外定义，整个文件（包括函数内）都能用
    局部变量：在函数内部定义，只能在函数内部用，外部无法访问
              （函数执行完毕后自动销毁）

    ⚠ 尽量避免在函数中使用全局变量，会使代码难以维护


【7】匿名函数 lambda
──────────────────────────────────────────────
    没有名称的函数，通过 lambda 表达式声明，适用于简单的单行函数

    格式：
        lambda 参数列表: 函数体

    ▸ 示例：
        out_line = lambda: print('..........')
        add = lambda x, y: x + y

        out_line()
        print(add(100, 200))

    ⚠ 注意
        - 逻辑简单、且只在一处使用时才考虑用，目的是简化书写
        - 通常作为高阶函数的参数（如 map、filter、sorted）
        - ★ 不需要写 return，表达式的运行结果就是返回值


【8】递归
──────────────────────────────────────────────
    在函数中自己调用自己
    ⚠ 递归调用一定要有终结点，否则无限递归

    ▸ 计算 n 的阶乘：
        def jc(n):
            if n == 1:              # ← 终结点
                return 1
            else:
                return n * jc(n - 1)

        print(jc(10))



════════════════════════════════════════════════════════════════════════════════
  五、类 型 注 解
════════════════════════════════════════════════════════════════════════════════

用于明确标识变量、函数参数和返回值的数据类型，使代码更清晰、更易维护。

⚠ 类型注解只是「提示」，不影响代码运行，解释器不会强制检查类型。


【1】变量类型注解
──────────────────────────────────────────────
    语法：变量名: 类型 = 值

        a: int        = 695
        score: float  = 98.5
        hobby: str    = "Python"
        flag: bool    = True
        pic: None     = None

        names:   list[str]            = ["A", "C", "E"]
        phones:  set[str]             = {"13309091111", "15209109121"}
        options: dict[str, int]       = {"count": 0, "total": 0}
        goods:   tuple[str, int, int] = ("手机", 5999, 1)


【2】函数类型注解
──────────────────────────────────────────────
    语法：def 函数名(参数: 类型, ...) -> 返回值类型:

    ▸ 有参数和返回值
        def add(x: int, y: int) -> int:
            return x + y

        def circle_area(r: float) -> float:
            return 3.14 * r * r

        def greet(name: str) -> str:
            return f"你好，{name}"

    ▸ 无返回值，标注为 None
        def say_hello(name: str) -> None:
            print(f"你好，{name}")

    ▸ 参数和返回值也可以是容器类型
        def get_top3(scores: list) -> list:
            scores.sort(reverse=True)
            return scores[:3]

    ▸ 类型注解 + 默认参数
        def reg_stu(name: str, age: int, gender: str, city: str = "北京") -> dict:
            return {"name": name, "age": age, "gender": gender, "city": city}



════════════════════════════════════════════════════════════════════════════════
  六、模 块 与 包
════════════════════════════════════════════════════════════════════════════════

【1】模块的概念
──────────────────────────────────────────────
    ★ 一个 .py 文件就是一个模块，是 Python 程序的基本组成单位
    模块中可以定义变量、函数、类以及可执行的代码

    优势：提高代码复用性、降低开发门槛、避免命名冲突


【2】导入模块
──────────────────────────────────────────────
    import 模块名
        ▸ import random                          →  random.randint(10, 100)

    import 模块名 as 别名
        ▸ import random as rd                    →  rd.randint(10, 100)

    from 模块名 import 功能名
        ▸ from random import randint, choice     →  randint(10, 100)   直接用

    from 模块名 import 功能名 as 别名
        ▸ from random import randint as rint     →  rint(10, 100)      直接用

    from 模块名 import *
        ▸ from random import *                   →  导入所有功能，直接用函数名

    ⚠ 注意
        - import 可一次导入多个模块，用 , 分隔：  import os, sys, math
        - from 模块名 import *  不推荐使用，可能造成命名冲突


【3】常用内置模块
──────────────────────────────────────────────
    os              文件、目录、系统环境操作
                    ▸ os.getcwd()                 → 获取当前工作目录
    sys             Python 解释器、命令行参数
                    ▸ sys.argv                    → 命令行参数列表
    math            数学计算
                    ▸ math.sqrt(16)               → 4.0
    random          随机数
                    ▸ random.randint(1, 10)       → 1~10 随机整数
    datetime        日期和时间
                    ▸ datetime.datetime.now()     → 当前时间
    json            JSON 数据读写
                    ▸ json.dumps({"a": 1})        → '{"a": 1}'
    re              正则表达式
                    ▸ re.search(r'\d+', "abc123")
    collections     常用高级数据结构
                    ▸ from collections import Counter


【4】自定义模块
──────────────────────────────────────────────
    模块名就是自己定义的文件名（导入时不需要带 .py）


【5】__name__ 变量
──────────────────────────────────────────────
    每个模块都有内置变量 __name__，用于判断当前模块是「直接运行」还是「被导入」

    ★ 直接运行本文件      →  __name__ 的值为 "__main__"
    ★ 被其他文件 import   →  __name__ 的值为本模块的文件名

    作用：把测试代码写在 if 里面，只有直接运行时才执行，被 import 时不触发

    ▸ 示例：my_utils.py
        def add(x, y):
            return x + y

        if __name__ == "__main__":
            print(add(3, 5))        # 只有直接运行 my_utils.py 才会打印


【6】包 package
──────────────────────────────────────────────
    本质就是一个文件夹，里面包含若干个模块，外加一个 __init__.py 描述包的信息
    作用：模块文件较多时用来管理多个模块（★ 包的本质也是一个模块）
    定义 __init__ 文件后，文件夹会自动变成软件包

    导入方式：
        import 包名.模块名
        from 包名 import 模块名
        from 包名.模块名 import 功能名



════════════════════════════════════════════════════════════════════════════════
  七、面 向 对 象 基 础
════════════════════════════════════════════════════════════════════════════════

【1】两种编程思想
──────────────────────────────────────────────
    面向过程编程
        把一个需求分解成一系列要执行的步骤，按步骤依次执行（关注流程、步骤）
        适用于一些简单线性编程

    面向对象编程
        ★ 万物皆对象 —— 对象的特征为「属性」，对象的功能为「方法」


【2】类与对象
──────────────────────────────────────────────
    类：描述一组具有相同属性和方法的模板
    对象：类的实例，是基于类创建出来的


【3】类的定义与对象的创建
──────────────────────────────────────────────

  ● 方法一（不推荐）—— 创建后再逐个赋属性

        class 类名:
            pass

        对象名 = 类名()
        对象名.属性名1 = 属性值1
        对象名.属性名2 = 属性值2

    ⚠ 类名遵循大驼峰：每个单词首字母大写、无分隔符，如 UserInfo、UserAccount
    ★ __dict__ 是实例的特殊属性，以字典形式储存对象的所有属性

  ● 方法二（推荐）—— 用 __init__ 初始化

        class 类名:
            def __init__(self, 参数列表):
                self.属性名 = 参数值
                self.属性名 = 参数值

        对象名 = 类名(参数列表)

    ★ self       方法的第一个参数，表示当前创建的实例对象
    ★ __init__   初始化方法，对象创建后自动调用，用于设置对象的初始状态
    ★ def        在类外称之为「函数」，在类中称之为「方法」

    ▸ 示例：
        class Car:
            def __init__(self, c_brand, c_name, c_price):
                self.brand = c_brand
                self.name  = c_name
                self.price = c_price

        c1 = Car("宝马", "X5", 800000)
        print(c1.__dict__)


【4】实例方法
──────────────────────────────────────────────
    在类中定义的函数称为方法，★ 第一个参数必须是 self
    通过对象来调用，调用时 self 自动传入，不需要手动传递

    格式：
        class 类名:
            def __init__(self, 参数列表):
                self.属性名 = 参数值

            def 方法名(self, 形参列表):
                # 方法体

    ▸ 示例：
        class Car:
            def __init__(self, c_brand, c_name, c_price):
                self.brand = c_brand
                self.name  = c_name
                self.price = c_price

            def show_info(self):
                print(f"品牌：{self.brand}，车型：{self.name}，价格：{self.price}")

            def discount(self, rate):
                self.price = self.price * (1 - rate)

        c1 = Car("宝马", "X5", 800000)
        c1.show_info()          → 品牌：宝马，车型：X5，价格：800000
        c1.discount(0.1)        # 打九折
        c1.show_info()          → 品牌：宝马，车型：X5，价格：720000.0


【5】魔法方法
──────────────────────────────────────────────
    以双下划线开头和结尾的特殊方法，用于定义类的特殊行为，比如 __init__
    ★ 不需要手动调用，由解释器自动调用

        __init__        初始化方法，对象创建时自动调用
        __str__         字符串表示，print(对象) 或 str(对象) 时调用
        __eq__          比较两个对象是否相等（equal），使用 ==  时调用
        __lt__          小于        <
        __le__          小于等于    <=
        __gt__          大于        >
        __ge__          大于等于    >=


【6】属性
──────────────────────────────────────────────
    实例属性：属于每个具体对象，各对象相互独立（每个对象特有的数据）
    类属性：  属于类本身，★ 所有实例共享

    ▸ 示例：
        class Student:
            school = "蓝翔技校"             # 类属性：所有学生共享

            def __init__(self, name, age):
                self.name = name            # 实例属性：每个学生各不相同
                self.age  = age

        stu1 = Student("小明", 18)
        stu2 = Student("小红", 19)

        print(stu1.school)                  → 蓝翔技校
        print(stu2.school)                  → 蓝翔技校

        Student.school = "新东方技校"        # 修改类属性
        print(stu1.school)                  → 新东方技校（stu1 也变了）
        print(stu2.school)                  → 新东方技校（stu2 也变了）



════════════════════════════════════════════════════════════════════════════════
  八、异 常
════════════════════════════════════════════════════════════════════════════════

【1】异常的概念
──────────────────────────────────────────────
    程序运行过程中出现的错误，会中断程序的正常执行流程

    常见异常类型：
        NameError               变量名不存在
        TypeError               类型错误（如 字符串 + 数字）
        ValueError              值错误（如 int("abc")）
        ZeroDivisionError       除数为零
        IndexError              列表索引超出范围
        KeyError                字典 key 不存在
        FileNotFoundError       文件未找到


【2】异常处理
──────────────────────────────────────────────
    不做处理  →  有 bug 就中断执行
    捕获异常  →  按自己的方式处理，处理完程序继续执行
                （编写程序时做好预案，出现异常按预案处理）

    语法：
        try:
            可能会出现异常的业务代码
        except [异常类型 as 变量名]:
            出现异常时的预案
        finally:
            不管是否出现异常，都会执行的代码

    ▸ 示例：
        try:
            num = int(input("请输入数字："))
            print(100 / num)
        except ValueError:
            print("输入的不是数字！")
        except ZeroDivisionError:
            print("除数不能为零！")
        except Exception as e:
            print(f"未知错误：{e}")
        finally:
            print("程序结束")

    ★ Exception 可以匹配所有类型的异常，一般写在最后兜底
