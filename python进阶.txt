  一、面 向 对 象 概 述
════════════════════════════════════════════════════════════════════════════════

面向对象是一种编程思想，★ 核心是把「数据」和「操作数据的方法」封装在一起。

★ 三大特性

    封装 Encapsulation      把属性和方法写进类里，并控制访问权限
    继承 Inheritance        子类获得父类的属性和方法，实现代码复用
    多态 Polymorphism       同一个方法调用，不同对象作出不同响应



════════════════════════════════════════════════════════════════════════════════
  二、类 与 对 象 基 础
════════════════════════════════════════════════════════════════════════════════

【1】类与对象
──────────────────────────────────────────────
    类 Class      抽象的概念，是创建对象的模板 / 蓝图
    对象 Object   具体的实体，是类实例化后的产物


【2】定义类的三种写法
──────────────────────────────────────────────
    1. class 类名:                  # 最简写法
    2. class 类名():                # 加括号
    3. class 类名(object):          ✔ 显式继承 object，推荐

    三种写法效果完全一样。

    创建对象：
        对象名 = 类名()


【3】访问类中的成员
──────────────────────────────────────────────
    Step 1  创建对象         对象名 = 类名()
    Step 2  用 对象名. 访问

        对象名.属性名        →  访问属性（名词，描述事物的外在特征）
        对象名.方法名()      →  调用方法（动词，描述事物的行为）


【4】self 关键字
──────────────────────────────────────────────
    self 是 Python 内置的关键字，★ 指向对象实例本身。

    作用：
        1. 一个类可以创建多个对象，每个对象都通过 对象名. 访问自己的成员
        2. 方法默认第一个参数是 self，Python 靠 self 区分是哪个对象在调用

    ★ 类内类外的写法对照
        位置        访问方式
        ─────────────────────────────────────────
        类外        对象名.属性  /  对象名.方法()
        类内        self.属性    /  self.方法()

    ▸ 示例：
        class Student:
            def __init__(self, name):
                self.name = name                    # self.name 是实例属性

            def study(self):
                print(f"{self.name} 在学习")         # self 指向调用它的那个对象

        s1 = Student("小明")
        s1.study()          → 小明 在学习

        s2 = Student("小红")
        s2.study()          → 小红 在学习



════════════════════════════════════════════════════════════════════════════════
  三、封 装（Encapsulation）
════════════════════════════════════════════════════════════════════════════════

封装就是把属性和方法书写到类里面的操作，并为它们添加私有权限、控制访问。

★ 目的
    - 简化编程：使用者不需要了解内部实现，只通过外部接口调用
    - 增强安全性：隐藏敏感数据，防止外部随意修改


【1】私有属性
──────────────────────────────────────────────
    格式：属性名前面加两个下划线 __（后面不加）
    ★ 效果：只能在类的内部使用，类的外部不能直接访问，也不会被子类继承

    ▸ 示例：
        class Person:
            def __init__(self, name, age):
                self.__name = name              # 私有属性
                self.__age = age                # 私有属性

            def get_name(self):                 # 公共接口：提供只读访问
                return self.__name

            def set_age(self, age):             # 公共接口：提供受控写入
                if age > 0:
                    self.__age = age

        p = Person("小明", 18)
        print(p.__name)         ✘ 报错！外部不能直接访问私有属性
        print(p.get_name())     ✔ 小明（通过公共接口安全访问）


【2】私有方法
──────────────────────────────────────────────
    格式同样是在方法名前面加 __，只能在类内部调用，外部和子类都无法访问。

    ▸ 示例：
        class BankAccount:
            def __init__(self, balance):
                self.__balance = balance

            def __check_balance(self):                  # 私有方法
                print(f"验证余额中...")
                return self.__balance

            def withdraw(self, amount):
                if self.__check_balance() >= amount:    # 内部调用私有方法
                    self.__balance -= amount
                    print(f"取款成功，余额：{self.__balance}")

        acc = BankAccount(1000)
        acc.withdraw(200)           ✔ 走公共方法
        acc.__check_balance()       ✘ 报错！不能从外部调用私有方法


【3】私有属性能被子类继承吗？
──────────────────────────────────────────────
    ⚠ 不能。带 __ 的属性 / 方法，子类无法直接继承。

    ▸ 示例：
        class Father:
            def __init__(self):
                self.money = 100                # 公有，子类能继承
                self.__secret = "秘密"          # 私有，子类拿不到

        class Son(Father):
            def show(self):
                print(self.money)               ✔ 100
                print(self.__secret)            ✘ 报错！子类也无法访问私有属性

    ★ 一句话总结
        想让子类继承  →  写 self.xxx
        不想让外部碰  →  写 self.__xxx



════════════════════════════════════════════════════════════════════════════════
  四、继 承（Inheritance）
════════════════════════════════════════════════════════════════════════════════

【1】基本概念
──────────────────────────────────────────────
    子类继承父类的所有属性和方法，使子类对象具有父类的特征和行为。
    ⚠ 继承的是「类」，不是「对象」。

    作用：提高代码复用性，建立类之间的层次关系
    缺点：耦合性增强，★ 父类的缺陷也会被子类继承
    别称：父类 = 基类       子类 = 派生类

    ▸ 示例：
        class Animal:                   # 父类（基类）
            def eat(self):
                print("吃东西")

        class Dog(Animal):              # 子类（派生类）
            def bark(self):
                print("汪汪叫")

        dog = Dog()
        dog.eat()       # 继承自父类的方法
        dog.bark()      # 自己的方法


【2】单继承 —— 一个子类只继承一个父类
──────────────────────────────────────────────
        class A:
            def say(self):
                print("A")

        class B(A):             # B 继承 A
            pass

        b = B()
        b.say()         → A     （子类没有，往上找父类）


【3】多继承 —— 一个子类继承多个父类
──────────────────────────────────────────────
        class A:
            def say(self):
                print("A")

        class B:
            def say(self):
                print("B")

        class C(A, B):          # 同时继承 A 和 B
            pass

        c = C()
        c.say()                 → A    （A 写在左边，优先用 A 的）
        print(C.__mro__)        # 查看方法解析顺序

    ★ MRO（Method Resolution Order 方法解析顺序）
        多个父类有同名方法时，按 MRO 顺序查找，先找到谁就用谁。
        规则：从左到右，深度优先，子类优先。

        查看方式：
            print(类名.__mro__)
            print(类名.mro())


【4】子类重写父类 Override
──────────────────────────────────────────────
    子类定义和父类同名的方法，★ 优先调用子类自己的。

        class Animal:
            def speak(self):
                print("动物叫")

        class Cat(Animal):
            def speak(self):            # 重写父类的 speak
                print("喵喵")

        cat = Cat()
        cat.speak()     → 喵喵     （用自己的，不用父类的）


【5】子类调用父类方法 —— super()
──────────────────────────────────────────────
    重写的同时还想用到父类的功能（适合单继承）。

        class Animal:
            def __init__(self, name):
                self.name = name

        class Dog(Animal):
            def __init__(self, name, breed):
                super().__init__(name)      # ★ 先调父类的 __init__ 设置 name
                self.breed = breed          #   再设置子类独有的属性

        dog = Dog("大黄", "金毛")
        print(dog.name)     → 大黄
        print(dog.breed)    → 金毛


【6】多层继承
──────────────────────────────────────────────
    一层一层往下继承：C → B → A，子类能调用所有祖先的方法。

        class A:
            def method_a(self):
                print("我是 A")

        class B(A):
            def method_b(self):
                print("我是 B")

        class C(B):                     # C → B → A
            def method_c(self):
                print("我是 C")

        c = C()
        c.method_a()    → 我是 A    （从祖父类 A 继承）
        c.method_b()    → 我是 B    （从父类 B 继承）
        c.method_c()    → 我是 C    （自己的）

    ★ 查找顺序：C → B → A → object，沿链条逐级往上找。


【7】抽象类
──────────────────────────────────────────────
    抽象类：只能被继承、不能直接创建对象的类，在 Python 中也叫接口
    抽象方法：没有方法体的方法（用 pass 占位）
    作用：充当父类，制定行业规范和准则，强制子类实现指定方法，具体实现交给子类

    ★ 三句话概括
        1. 抽象类自己不能实例化
        2. 子类必须重写所有抽象方法，否则子类也无法实例化
        3. 用 from abc import ABC, abstractmethod 来定义

    ▸ 示例：空调抽象类
      ⚠ 下面是「只定规范」的简化写法，没有引入 abc 模块，因此不会真正强制子类实现

        # 定义抽象类 —— 定规则
        class AC:
            def cool_wind(self):        # 制冷
                pass
            def hot_wind(self):         # 制热
                pass
            def swing_l_r(self):        # 左右摆风
                pass

        # 子类1：小米空调
        class Xiaomi(AC):
            def cool_wind(self):
                print("小米空调制冷风")
            def hot_wind(self):
                print("小米空调制热风")
            def swing_l_r(self):
                print("小米空调左右摆风")

        # 子类2：格力空调
        class Gree(AC):
            def cool_wind(self):
                print("格力空调制冷风")
            def hot_wind(self):
                print("格力空调制热风")
            def swing_l_r(self):
                print("格力空调左右摆风")

        xm = Xiaomi()
        xm.cool_wind()      → 小米空调制冷风
        gr = Gree()
        gr.cool_wind()      → 格力空调制冷风



════════════════════════════════════════════════════════════════════════════════
  五、多 态（Polymorphism）
════════════════════════════════════════════════════════════════════════════════

【1】什么是多态
──────────────────────────────────────────────
    多态就是「多种状态」—— 同一个函数在不同场景下有不同的表现。
    不同类的对象对同一个方法调用，作出各自不同的响应。

    ★ Python 靠的是「鸭子类型」：只要对象有同名方法就能直接调，不关心它是什么类。


【2】多态的三大前提条件
──────────────────────────────────────────────
    1. 要有继承（子类继承父类）
    2. 要有方法重写（子类覆盖父类方法），不然多态无意义
    3. 要有父类引用指向子类对象


【3】继承实现多态
──────────────────────────────────────────────
    子类重写父类方法，同一个函数对不同子类对象产生不同行为：

        class Animal:
            def speak(self):
                pass

        class Cat(Animal):
            def speak(self):
                print("喵喵")

        class Dog(Animal):
            def speak(self):
                print("汪汪")

        class Duck(Animal):
            def speak(self):
                print("嘎嘎")

        def animal_sound(animal):       # 同一个函数
            animal.speak()              # 同一个方法调用

        animal_sound(Cat())     → 喵喵
        animal_sound(Dog())     → 汪汪
        animal_sound(Duck())    → 嘎嘎
        # 不同对象，同一句 animal.speak()，结果不同


【4】鸭子类型 —— Python 多态的核心理念
──────────────────────────────────────────────
    ★ 不需要继承同一个父类，只要方法名一样就能统一调用。

        class Car:
            def run(self):
                print("汽车在公路上跑")

        class Boat:
            def run(self):
                print("船在水上跑")

        class Plane:
            def run(self):
                print("飞机在跑道上跑")

        def start(vehicle):             # 不关心是什么类型
            vehicle.run()               # 只要你有 run 方法就行

        start(Car())        → 汽车在公路上跑
        start(Boat())       → 船在水上跑
        start(Plane())      → 飞机在跑道上跑


【5】多态的好处
──────────────────────────────────────────────
    - 提高灵活性：新增一个类，只要实现了同名方法，老代码不用改直接就能用
    - 降低耦合：调用方不需要知道对象的具体类型，只关心有没有对应方法
    - 代码简洁：不需要写一大堆 if/else 判断类型


【6】对比：没有多态 vs 有多态
──────────────────────────────────────────────
    ✘ 没有多态 —— 每新增一种动物都要改函数
        def make_sound(animal):
            if type(animal) == Cat:
                print("喵喵")
            elif type(animal) == Dog:
                print("汪汪")
            elif type(animal) == Duck:      # 每次加新动物都得来加一个 elif
                print("嘎嘎")

    ✔ 有多态 —— 新增动物完全不用改这个函数
        def make_sound(animal):
            animal.speak()                  # 管你是什么，有 speak 方法就调用



════════════════════════════════════════════════════════════════════════════════
  六、魔 法 方 法（Magic Methods）
════════════════════════════════════════════════════════════════════════════════

魔法方法（Magic / Dunder Methods）是 Python 内置的特殊方法，
★ 总是被双下划线 __ 包围，在特定时机自动调用，不需要开发者手动调用。

常见魔法方法一览：
──────────────────────────────────────────────
    __init__        创建对象时自动调用              →  构造方法
    __str__         print(对象) / str(对象) 时调用   →  给人看的描述
    __repr__        交互环境中直接输入对象名时调用    →  给开发者看的调试信息
    __del__         对象被销毁时自动调用             →  析构方法
    __len__         len(对象) 时调用                →  获取长度
    __eq__          对象 == 对象 时调用             →  判断相等
    __lt__          对象 <  对象 时调用             →  小于比较
    __gt__          对象 >  对象 时调用             →  大于比较
    __add__         对象 +  对象 时调用             →  加法运算
    __call__        对象() 直接当函数调用时          →  让实例可调用


【6.1】__init__ —— 构造方法
──────────────────────────────────────────────
    触发时机：每当创建一个新对象时，__init__ 自动执行
    作用：初始化对象的属性，给对象设置初始状态

    基本格式：
        class 类名:
            def __init__(self):
                # 初始化代码

  ● 无参 __init__（不需要传参）
    适用于：所有对象的初始属性值都一样

        class Dog:
            def __init__(self):
                self.name = "旺财"              # 写死默认值
                self.age = 1
                print("一只小狗出生了！")

        dog1 = Dog()            # 自动调用 __init__  → 一只小狗出生了！
        dog2 = Dog()
        print(dog1.name)        → 旺财
        print(dog2.name)        → 旺财（和 dog1 一样的默认值）

  ● 有参 __init__（需要传参）★ 更常用
    适用于：每个对象的属性值不同

        class Dog:
            def __init__(self, name, age):
                self.name = name                # 用传入的参数给属性赋值
                self.age = age

        dog1 = Dog("大黄", 2)
        dog2 = Dog("小白", 1)
        print(dog1.name, dog1.age)      → 大黄 2
        print(dog2.name, dog2.age)      → 小白 1

  ● 有参 + 默认值（可选参数）
    给参数设置默认值，创建对象时有些参数可传可不传

        class Dog:
            def __init__(self, name, age=1):    # age 有默认值 1
                self.name = name
                self.age = age

        dog1 = Dog("大黄", 3)       # 传了 age，用 3
        dog2 = Dog("小白")          # 没传 age，用默认值 1
        print(dog1.age)             → 3
        print(dog2.age)             → 1

  ★ 总结对比
              定义时                       创建对象时              适用场景
    ─────────────────────────────────────────────────────────────────────────
    无参       def __init__(self):         对象名 = 类名()         所有对象初始值相同
    有参       def __init__(self, ...):    对象名 = 类名(参数)     每个对象属性值不同


【6.2】__str__ —— 打印字符串
──────────────────────────────────────────────
    触发时机：使用 print(对象) 或 str(对象) 时自动调用
    作用：返回一个易读的字符串，方便查看对象的信息
    ⚠ 必须 return 一个字符串（不能 print）

  ● 没有 __str__ 时 —— 打印的是内存地址（看不懂）

        class Student:
            def __init__(self, name, age, score):
                self.name = name
                self.age = age
                self.score = score

        s1 = Student("小明", 18, 95)
        print(s1)       → <__main__.Student object at 0x000001A2B3C4D5E0>
        print(str(s1))  → 和上面一样，也是地址

  ● 重写 __str__ 后 —— 打印的是属性信息（清晰明了）

        class Student:
            def __init__(self, name, age, score):
                self.name = name
                self.age = age
                self.score = score

            def __str__(self):
                return f"姓名：{self.name}，年龄：{self.age}，成绩：{self.score}"

        s1 = Student("小明", 18, 95)
        s2 = Student("小红", 17, 88)

        print(s1)       → 姓名：小明，年龄：18，成绩：95   （自动调用 __str__）
        print(s2)       → 姓名：小红，年龄：17，成绩：88

  ⚠ 易错：打印「列表」时，列表内部调的是 __repr__ 而不是 __str__

        students = [s1, s2]
        print(students)     → [<__main__.Student object at 0x...>, ...]  还是地址！

        # 解决办法：要么同时定义 __repr__，要么手动遍历打印
        for s in students:
            print(s)        ✔ 这样才会调用 __str__


【6.3】__del__ —— 析构方法
──────────────────────────────────────────────
    触发时机：对象在内存中被销毁时自动调用
    作用：做收尾清理工作，比如关闭文件、释放资源、保存数据等
    ⚠ 一般靠 Python 垃圾回收自动处理，很少手动 del

  ● 基本示例 —— 观察对象的「出生」和「消亡」

        class Dog:
            def __init__(self, name):
                self.name = name
                print(f"{self.name} 出生了")

            def __del__(self):
                print(f"{self.name} 被回收了")

        # 场景1：手动删除
        dog = Dog("大黄")       → 大黄 出生了
        del dog                 → 大黄 被回收了（手动触发）

        # 场景2：程序结束时自动删除
        dog2 = Dog("小白")      → 小白 出生了
                                  ...程序结束...
                                → 小白 被回收了（自动触发）

  ● 实用示例 —— 自动关闭文件

        class FileWriter:
            def __init__(self, filename):
                self.filename = filename
                self.file = open(filename, "w", encoding="utf-8")
                print(f"文件 {filename} 已打开")

            def write(self, content):
                self.file.write(content)

            def __del__(self):
                self.file.close()               # ★ 对象销毁时自动关闭文件
                print(f"文件 {self.filename} 已自动关闭")

        fw = FileWriter("test.txt")
        fw.write("hello world")
        del fw          # 自动调用 __del__，文件被正确关闭，不会造成资源泄漏

  ● ★ 同一个对象被多个变量引用时 —— 删掉最后一个引用才会触发

        class Demo:
            def __init__(self, name):
                self.name = name
            def __del__(self):
                print(f"{self.name} 被删除")

        a = Demo("测试对象")
        b = a                   # b 也指向同一个对象
        del a                   # 什么都没发生！因为 b 还引用着它
        print("删掉了 a，但对象还在")
        del b                   → 测试对象 被删除（最后一个引用没了，才触发）

  ⚠ 注意事项
        1. __del__ 的调用时机不确定，不要依赖它来做关键逻辑
        2. 如果程序崩溃，__del__ 可能不会被调用
        3. 循环引用的对象，垃圾回收器可能无法正常回收



════════════════════════════════════════════════════════════════════════════════
  七、对 象 属 性 与 类 属 性
════════════════════════════════════════════════════════════════════════════════

【1】区分
──────────────────────────────────────────────
    对象属性：属于每个对象，定义在 __init__ 里，每个对象各自独立
    类属性：  属于类本身，定义在类中、函数外，被该类下所有对象共享

                    对象属性                     类属性
    ─────────────────────────────────────────────────────────────
    定义位置        __init__ 里面                类中、函数外
    调用方式        只能 对象名.                 推荐 类名.（也可 对象名.）
    数据归属        每个对象各自独立             该类所有对象共享

    ▸ 示例：学生信息
        class Student:
            school = "武汉大学"                  # 类属性（定义在函数外）

            def __init__(self, name, age):
                self.name = name                # 对象属性（定义在 __init__ 里）
                self.age = age

            def __str__(self):
                return f"姓名: {self.name}, 年龄: {self.age}"

        s1 = Student("张三", 20)
        s2 = Student("李四", 22)

        print(s1.school)        → 武汉大学（对象名.类属性 → 能读）
        print(Student.school)   → 武汉大学（类名.类属性 → ✔ 推荐方式）


【2】★ 重点：修改类属性的正确姿势
──────────────────────────────────────────────
    ✘ 这样改不了类属性，只是给当前对象新建了一个同名实例属性
        s2.school = "清华大学"
        print(Student.school)   → 武汉大学（类属性没变！）
        print(s1.school)        → 武汉大学（s1 没有自己的 school，往上找类）
        print(s2.school)        → 清华大学（s2 自己的实例属性，挡住了类属性）

    ✔ 这样才是真正修改类属性，所有对象都受影响
        Student.school = "清华大学"
        print(s1.school)        → 清华大学（类属性改了，s1 跟着变）
        print(s2.school)        → 清华大学（同理）

    ★ 记住一句话
        读取时找不到会往上找类，写入时只往自己身上写。



════════════════════════════════════════════════════════════════════════════════
  八、类 方 法 与 静 态 方 法
════════════════════════════════════════════════════════════════════════════════

【1】三者对比
──────────────────────────────────────────────
                    第一个参数            装饰器
    ──────────────────────────────────────────────
    普通方法        self（实例对象）      不需要
    类方法          cls（类对象）         @classmethod
    静态方法        无特殊参数            @staticmethod


【2】类方法
──────────────────────────────────────────────
    类所拥有的方法，★ 第一个参数必须是 cls（代表类本身）

        class Student:
            count = 0                           # 类属性：统计学生总数

            def __init__(self, name):
                self.name = name
                Student.count += 1

            @classmethod
            def get_count(cls):                 # cls = Student 类对象
                print(f"当前共有 {cls.count} 名学生")

        s1 = Student("小明")
        s2 = Student("小红")
        Student.get_count()     → 当前共有 2 名学生   ✔ 推荐：类名.调用
        s1.get_count()          # 也可用对象调，但不推荐


【3】静态方法
──────────────────────────────────────────────
    放在类里的普通函数，★ 不需要 self 也不需要 cls，纯粹做逻辑归类

        class MathTool:
            @staticmethod
            def add(a, b):
                return a + b

            @staticmethod
            def max_of_three(a, b, c):
                return max(a, b, c)

        print(MathTool.add(3, 5))               → 8   （直接类名调，无需创建对象）
        print(MathTool.max_of_three(1, 5, 3))   → 5


【4】★ 什么时候用哪个？
──────────────────────────────────────────────
    方法里需要                    定义成
    ─────────────────────────────────────────
    实例属性（self.name）         普通方法
    类属性（cls.xxx）             类方法
    都不需要，纯工具函数          静态方法
